# StoryWalker website

Statický web pro GitHub Pages.

## Struktura

- `/index.html` – hlavní prezentační stránka
- `/manual/` – rozcestník dokumentace
- `/manual/player/` – příručka hráče
- `/manual/author/` – příručka autora rozdělená do samostatných kapitol
- `/adventures/` – základ budoucí knihovny dobrodružství
- `/privacy.html` – zásady ochrany soukromí (stávající veřejná adresa zachována)
- `/assets/site.css` – společné styly nových vícestránkových sekcí
